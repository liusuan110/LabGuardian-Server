3. **反馈环路问题**：如果反馈环路没有正确连接，可能会导致放大器输出饱和。检查反馈环路的连接是否正确，确保 Rf 的电阻值和引脚正确。

4. **运放输出饱和**：运放的输出饱和是由于输入信号过大，超过了运放的动态范围。检查输入信号的幅度和频率，确保输入信号在允许的范围内。

综上所述，输出始终在 +12V 可能是由于电源电压问题、输入信号问题、反馈环路问题或运放输出饱和。需要逐一排查这些因素，确保电路正常工作。
